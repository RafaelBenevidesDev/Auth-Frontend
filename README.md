# Auth Frontend

Interface de autenticação e dashboard construída com React e Vite.

## Tecnologias

- React 19
- Vite
- React Router DOM
- Axios
- CSS customizado com dark/light mode

## Funcionalidades

- Tela de login e cadastro
- Dashboard com perfil do usuário
- Edição de informações pessoais
- Alternância entre modo claro e escuro
- Integração com a Auth API

## Como rodar

### 1. Instalar dependências
```bash
npm install
```

### 2. Rodar o projeto
```bash
npm run dev
```

Acesse http://localhost:5173
